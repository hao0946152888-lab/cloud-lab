Câu 79. Dừng Backend và Frontend

docker stop mern-backend mern-frontend

Đã thực hiện; container cũ đã được dừng trước khi chạy Compose.

Câu 80. Tạo docker-compose.yml

cd /workspaces/cloud-lab
touch docker-compose.yml

File đã tạo tại thư mục gốc Repository.

Câu 81. Khai báo service Backend

services:
  backend:
    build:
      context: ./mern-demo
      dockerfile: server/Dockerfile

Câu 82. Khai báo service Frontend

services:
  frontend:
    build:
      context: ./mern-demo/client
      dockerfile: Dockerfile

Câu 83. Port Backend

ports:
  - "5000:5000"

Truy cập Backend qua http://localhost:5000/api/hello.

Câu 84. Port Frontend

ports:
  - "8080:80"

Truy cập Frontend tại http://localhost:8080.

Câu 85. Biến môi trường MongoDB

environment:
  MONGODB_URI: ${MONGODB_URI:?MONGODB_URI must be set}

Giá trị được nạp an toàn từ mern-demo/.env bằng tùy chọn --env-file.

Câu 86. Khởi động toàn bộ ứng dụng

docker compose --env-file mern-demo/.env up -d --build

Đã build và khởi động thành công.

Câu 90. Lấy danh sách sinh viên từ MongoDB Atlas

Mở kết quả API danh sách sinh viên

Câu 91. Thêm sinh viên và kiểm tra Atlas

Mở Form React, nhập MSSV, họ tên, email rồi bấm “Thêm sinh viên”. Hoặc chạy lệnh mẫu:

curl -X POST http://localhost:8080/api/students \
  -H "Content-Type: application/json" \
  -d '{"studentId":"TEST-DOCKER-001","name":"Sinh Vien Docker","email":"docker-test@example.com"}'

curl http://localhost:8080/api/students

Sau đó mở MongoDB Atlas → Database → Browse Collections → students để chụp bản ghi.
